# ops/metrics/

One CSV per signal in `../bands.yaml`. Two columns, append-only:

```
# ISO-8601 UTC timestamp, value
2026-08-29T03:11:04Z,41.8
```

Comment lines start with `#`, and a text first row is treated as a header and
skipped.

Empty at M0. The signals are declared and the detector is wired, but the
measurements do not exist yet — `claims/0001-ring-submit-latency.toml` says the
same thing about the same number, and for the same reason. `detect.sh` reports
"no history yet" rather than failing, and reports "too few to say anything"
below eight samples.

Nothing here is generated by hand. Each history is appended by the job that
produces the number: the claim run, the boot check, the unsafe-percentage
report. A row typed by a person is a row that cannot be traced to a run.
